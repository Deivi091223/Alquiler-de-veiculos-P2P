# Alquiler-de-veiculos-P2P
Plataforma web P2P para alquilar vehículos (autos, motos y utilitarios) entre particulares por horas o días. Incluye reservas, microseguro, check-in/check-out con fotos geolocalizadas y validación de peritajes por administradores. Proyecto Integrador - Técnico en Desarrollo de Software.
